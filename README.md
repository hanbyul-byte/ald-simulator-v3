## 역설계
- `ald_model.inverse_design()`: 증착 온도(1 °C)·전구체 온도(0.5 °C)·dose 격자를 전부 평가해 제약(평균 두께 ± 허용 오차,
  불균일도 1σ 상한, 최소 포화도)을 만족하는 조건 중 목표(불균일도 / 전구체 사용량 / 증착 온도 최소)가 가장 좋은 5개를 추천.
- 불균일도 = √(모델 예측² + 모델 밖 편차²). 모델 밖 편차 기본값은 측정 맵 중 가장 균일한 맵(전구체 55 °C / 증착 225 °C, 1.91 %).
- 전구체 사용량 = dose × 증기압비 × 사이클 (논문 조건 = 1). 사이클 조정은 ALD 선형 성장 가정.
- 9점 맵이 측정된 조건 근처면 '측정 맵 인근', 아니면 '외삽'으로 표시.
- HTML(JS)과 Python 구현은 같은 입력에서 같은 추천을 냄 (9개 시나리오로 확인).

## 모델
- **포화 front + 흐름 jet** (기본): Langmuir 흡착 + 유선 방향 질량수지에서 유도한 로지스틱 포화도.
  `x_s`, `w`, `f₀`는 경험항.
- **기존 모델**: `P(d) = P₀·exp(−d/L_dep)`, Inlet 거리 d만의 함수.

## 주의
- 파라미터는 논문 Fig. 1a, 1b(전구체 55 °C 행)에서 판독한 75점으로 피팅한 값입니다.
  공정 조건으로부터 계산한 사전 이론값이 아닙니다.
- 9점은 웨이퍼 중심에서 반경 3 cm 안쪽에만 있으므로, 가장자리(반경 3–4.5 cm)의 예측은 외삽입니다.
  특히 jet 항 때문에 고온에서도 위쪽 양 끝이 얇게 나오는 것은 데이터로 확인되지 않은 부분입니다.
- 전구체 60–75 °C의 9점 맵 28개는 아직 판독하지 않았습니다. 데이터 탭에 추가하면 피팅에 바로 반영됩니다.
