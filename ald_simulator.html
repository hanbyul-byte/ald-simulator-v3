추천 조건

불균일도 = √(모델 예측² + 모델 밖 편차²). 전구체 사용량 = dose × 증기압비(전구체 온도) × 사이클, 논문 조건(전구체 55 °C, dose 1, 사이클 1) = 1. '적용'을 누르면 웨이퍼 맵 탭에서 그 조건을 확인할 수 있습니다.

균일도 vs 전구체 사용량

두께·포화도 조건을 만족하는 후보 전체(회색)와 Pareto 최적선. 왼쪽 아래로 갈수록 좋습니다.

가능 영역

색 = 불균일도 1σ, 회색 = 조건 불만족, 검은 점 = 9점 맵이 측정된 조건, 숫자 = 추천 순위

해석할 때 주의할 점

    실선 = 모델, 빈 원 = 측정 데이터 (현재 조건과 같은 전구체/증착 온도, 같은 지점일 때만 표시)

    식의 형태는 물리(Langmuir 흡착, 유선 방향 질량수지, Arrhenius, Clausius–Clapeyron)에서 왔지만, 파라미터 값은 모두 측정 데이터에 맞춘 것입니다. 사전 이론값과의 비교는 아직 들어 있지 않습니다.

    모델 비교

    각 증착 온도의 데이터를 통째로 빼고 나머지로 피팅한 뒤, 빠진 온도를 예측한 RMSE

    예측 vs 실측

    A. 모델 맵의 Zernike 분해 · 3단계에서 Z-Reg가 예측할 저차 구조가 어떤 모드로 이루어지는지 확인합니다.

    초록 = 축대칭(m=0), 주황 = 방위각 성분

    B. 실측 잔차의 저차 Zernike 분해 · 9점으로는 2차(6개 모드)까지만 안정적으로 추정됩니다.

    3단계 아이디어: 공정 조건 → 이 6개 잔차 계수를 예측하는 작은 회귀 모델(Z-Reg)을 학습해 물리 모델에 더합니다. 측정점이 없는 가장자리(웨이퍼 중심에서 3 cm 바깥)는 외삽입니다.

    모델 식과 가정

    포화 front + 흐름 jet (유선 x를 따라 Inlet에서 y만큼 떨어진 지점)

    H_sat(T) = H₀ · exp[−b (T − 100)],   a(T) = a₀ · exp[−Eₐ/R · (1/T − 1/373)]

    L_f(x) = Λ · P_v(T_p)/P_v(55 °C) · H₀/H_sat(T) · dose · exp[−(x − x_s)² / 2w²]

    dG/dy = −n_s (1 − e^(−aG/n_s))  ⇒  θ = (e^(aL_f) − 1) e^(−ay) / [1 + (e^(aL_f) − 1) e^(−ay)]

    t_ox = H_sat(T) · [f₀ + (1 − f₀) θ]

    기존 모델: P(d) = P₀ exp(−d/L_dep), θ = 1 − exp(−k · P_v · dose · P(d)/P₀ · H₀/H_sat), d = Inlet 거리

    • θ는 front 위치 y_f ≈ L_f를 중심으로 한 로지스틱 함수이고, a가 작은 극한에서는 기존 exp(−d/L_dep) 모델로 돌아갑니다.
    • x_s, w, f₀는 데이터 모양을 보고 넣은 경험항입니다.
    • 모든 파라미터는 논문 그림 판독 데이터(Fig. 1a, 1b 전구체 55 °C 행)로 피팅한 값이며, 공정 조건으로부터 계산한 사전 이론값이 아닙니다. 판독 오차가 있을 수 있습니다.
    • 9점은 웨이퍼 중심에서 반경 3 cm 안쪽에만 있어 가장자리 예측은 외삽입니다.
